Drop your real product screen recordings here to replace the UI mockups in `presentation.html`:

| Scene | Filename | Description |
| :--- | :--- | :--- |
| **Scene 2** | `scene2_offline_grading.mp4` | Flutter app in Airplane Mode grading a photographed tomato tray. |
| **Scene 3** | `scene3_cloud_audit.mp4` | Backend terminal or Swagger UI showing Celery sync, Spark audit, Wonder arbitration, and SAM 3.1 mask overlay. |
| **Scene 4** | `scene4_tamil_voice.mp4` | Recording of speaking the Tamil harvest sentence into the app and returning structured JSON. |
| **Scene 5** | `scene5_advisor_guardrail.mp4` | Advisor screen with real numbers and log output showing discarded invented number. |

Once dropped in, `presentation.html` automatically detects the video files and plays them inside the scene's media frame!
